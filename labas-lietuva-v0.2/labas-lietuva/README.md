# Labas Lietuva — prototype v0.2

Mobile-first Lithuanian learning PWA with eight introductory sample lessons and optional email authentication/cloud sync via Supabase.

**Start here:** [SETUP.md](SETUP.md) for GitHub Pages deployment, iPhone Home Screen installation, and Supabase configuration.

Local run: `python3 -m http.server 8000` from this directory, then open http://localhost:8000.

Includes: A1/A2/B1/B2 sample lesson selection; multiple choice, sentence building, writing, listening prompts; VI/EN toggle; XP/hearts/streak; flashcard preview; local JSON export; optional email sign-in and cloud progress storage with RLS.

Not included: complete A1–B2 course, automatic pronunciation scoring, verified native-speaker recordings, robust spaced repetition, conflict-free offline cloud sync. See SETUP.md.
